# Evaluation photos

Put the test photos here (JPEG, PNG or WebP). Everything in this folder except this file is ignored by git, so photos of real tables and people's hands stay off the public repo.

Name files so the layout and lighting are easy to read, for example `rows-shade-01.jpg`, `grouped-gymlight-03.jpg`, `mixed-lowsun-02.jpg`. Each file needs an entry in `../labels.json`.

See `../README.md` for how to shoot and label them.
